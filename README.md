# Enterprise Network Labs

A collection of hands-on enterprise networking labs built with **Cisco Packet Tracer** and **GNS3**, focused on practical networking skills, real-world topologies, and troubleshooting.

## 🎯 Goals

- Build and document enterprise network topologies.
- Practice CCNA concepts through hands-on implementation.
- Develop troubleshooting and network design skills.
- Progress from basic labs to advanced enterprise scenarios.

## 🛠️ Technologies

- **Cisco Networking** — Routing, switching, VLANs, OSPF, ACLs, and more.
- **GNS3 & Packet Tracer** — Network simulation and lab environments.
- **Future additions** — Firewalls, MikroTik, virtualization, Linux servers, and Zabbix monitoring.

## 📈 Lab Levels

Labs range from **beginner and intermediate** to advanced scenarios as the repository evolves.

## 📂 Repository Structure

Each lab includes its topology, configurations, addressing scheme, and documentation where applicable.
